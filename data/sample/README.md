# Muestras sintéticas

La Fase 2 incorporará un dataset inventado, identificado expresamente como
sintético, para desarrollar y probar los formatos actuales de Timeline. Antes de
crear los parsers se investigarán sus variantes Android, iOS y Takeout.

La muestra cubrirá 2–3 años: base en una ciudad europea, viajes por varias
ciudades de Europa y a Asia y América, con vuelos, tren y coche. No representa
el historial de Alfonso ni se obtiene de exportaciones personales.

Los fixtures con firmas de datos crudos deberán generarse de forma reproducible
o contar con una excepción de privacidad concreta y probada. No se excluye esta
carpeta completa del control de privacidad. Por ahora no hay datos de muestra.
